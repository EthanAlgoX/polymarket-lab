# Polymarket Lab v0.1.0

Initial source release with a categorized public market catalog, bounded REST orderbook scanning, Market WebSocket monitoring, fee/depth-aware paper analysis, and a shared research interface. Optional DeepSeek translation provides Chinese/English market text with persistent caching. Includes local SQLite records, CSV export, tests, CI, Docker, and macOS/Windows launch scripts.

This release cannot connect a wallet or submit an order. All result figures are simulated estimates derived from public data and are not a guarantee of execution or profit.
