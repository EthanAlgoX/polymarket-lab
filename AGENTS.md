# Agent instructions

Keep this project strictly public-data-only. Never add wallet connectivity, wallet secret configuration, signing, authenticated trading APIs, order submission, transfers, approvals, or geographic bypass. The user has authorized LLM APIs for translating public market text only. Read and use credentials exclusively on the backend from environment variables, an ignored local .env, or the website’s ignored local data/llm-config.json configuration (owner-only permissions). Never return saved credentials to the browser, log them, or commit them. Default the website to English; allow Chinese only with a user-configured API. Support DeepSeek and public HTTPS OpenAI-compatible Chat Completions providers; never reuse credentials when the destination changes. Translation must not change original market data, outcome/token order, financial calculations, or settlement identifiers. Financial calculations must remain Decimal-based. Do not mark live verification as successful unless the public endpoints were actually reached in that run. Run lint, tests, and the security scanner before commits.

Translation cost preference: default to the cheapest available model on the official DeepSeek API; currently deepseek-flash (DeepSeek V4.1 Flash, price verified 2026-10-02). Disable thinking, batch visible text, and reuse persistent translations. Corrective retries must use the same cheap model; never automatically upgrade to a more expensive model. Verify official availability and prices before changing this default.
